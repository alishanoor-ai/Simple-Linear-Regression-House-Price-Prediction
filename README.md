# Simple Linear Regression – House Price Prediction

## 📌 Project Overview

This project demonstrates a simple **Machine Learning regression model** using **Linear Regression** to predict house prices based on house size.

The model learns the relationship between historical house sizes and their prices, then uses this learned pattern to predict the price of a new house.

## 🎯 Objective

The main objective of this project is to understand the basic Machine Learning workflow:

**Data → Training → Learning Patterns → Prediction**

## 🛠️ Technologies & Libraries

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn

## 📊 Dataset

The dataset contains two main variables:

| Variable      | Description                      |
| ------------- | -------------------------------- |
| `House_Size`  | Size of the house in square feet |
| `House_Price` | Price of the house               |

## 🔍 Project Workflow

1. Imported the required Python libraries.
2. Created a sample house price dataset.
3. Checked the dataset and missing values.
4. Separated the input feature (`X`) and target variable (`y`).
5. Created a **Linear Regression** model using Scikit-Learn.
6. Trained the model using historical data.
7. Visualized the relationship between house size and price.
8. Used the trained model to predict the price of a new house.

## 🤖 Machine Learning Model

The project uses:

**Simple Linear Regression**

The model learns how house price changes according to house size and uses this relationship to make predictions for new data.

## 📈 Visualization

A scatter plot and regression line are used to visualize the relationship between:

**House Size ↔ House Price**

## 🔮 Prediction

After training, the model was used to predict the price of a **1700 sq ft** house.
